# Android Clicker Game

**Android Clicker Game** — это классическая инкрементальная игра (кликер) для устройств на базе Android. Игроки зарабатывают очки (монеты) простым нажатием на экран, покупают улучшения и автоматизируют процесс генерации ресурсов.

## 🚀 Особенности

*   **Классический геймплей:** Нажимай на главный элемент экрана и получай очки.
*   **Система улучшений (Upgrades):** Покупай пассивный доход (CPS — Clicks Per Second) или увеличивай силу одного клика (CPC — Clicks Per Click).
*   **Сохранение прогресса:** Текущий баланс и купленные апгрейды автоматически сохраняются при выходе из приложения.
*   **Адаптивный UI:** Оптимизированный интерфейс под любые разрешения экранов Android-устройств.
*   **Анимации и звуки:** Тактильный отклик и плавные визуальные эффекты при нажатии.

## 🛠 Стек технологий

*   **Язык программирования:** Kotlin / Java
*   **Интерфейс:** Jetpack Compose / XML Layouts
*   **Хранение данных:** SharedPreferences / Room Database (для сохранения прогресса)
*   **Архитектура:** MVVM (Model-View-ViewModel)

## 📦 Сборка и запуск

Для запуска проекта локально вам понадобятся [Android Studio](https://developer.android.com/studio) и установленный Android SDK.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/diyora-eng/android-clicker-game
   cd clicker-game-android
   ```

2. **Откройте проект:**
    * Откройте Android Studio.
    * Нажмите `File -> Open` и выберите корневую папку склонированного проекта.

3. **Синхронизируйте Gradle:**
    * Дождитесь окончания сборки проекта и загрузки всех зависимостей (Gradle Sync).

4. **Запустите приложение:**
    * Подключите Android-устройство по USB (в режиме отладки) или запустите встроенный эмулятор.
    * Нажмите кнопку **Run** (зеленый треугольник) на верхней панели Android Studio.

## 📂 Структура проекта

```text
app/
├── src/
│   ├── main/
│   │   ├── java/com/example/clickergame/
│   │   │   ├── data/          # Модели данных и репозитории (сохранение)
│   │   │   ├── ui/            # Экраны, ViewModels и компоненты интерфейса
│   │   │   └── viewmodel/     # Бизнес-логика игры

└── build.gradle.kts           # Конфигурация сборки модуля app
```
